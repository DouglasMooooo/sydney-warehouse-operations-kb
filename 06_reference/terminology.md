# Terminology

- SH — Sales Order document number.
- FHTZD — 发货通知单 / Shipping Notice.
- XSCKD — 销售出库单 / Sales Outbound.
- Prepared — physical stock prepared; not outbound.
- Outbound — physically left inventory.
- Repair_Good — 维修良品 / 悉尼良品仓.
