# Status Dictionary

- 已审核 — approved; still validate warehouse, quantity and inventory effect.
- 暂存 — draft/build stage; closure incomplete.
- 重新审核 — document exists; downstream validation/approval incomplete.
- 调查中 — evidence/query incomplete.
- superseded — historical conclusion replaced by later evidence.
