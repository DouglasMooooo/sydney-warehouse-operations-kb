# SH-2608-00172641

This case verified the semi-automated Sales Order → FHTZD workflow using Playwright with explicit user authorisation.

## Source lines selected

- `97-141-00060-B0`, 销售数量 `1.000`
- `97-223-00088-00`, 销售数量 `1.000`

The corresponding negative-quantity reversal lines were not selected.

## FHTZD values

- 起运港: `悉尼办公室`
- Detail row 1 出货仓库: `悉尼良品仓`
- Detail row 2 出货仓库: `悉尼良品仓`
- Generated FHTZD: `75-FHTZD260806040`

## Verified automation lessons

1. Search once and wait for the intended SH to appear before selecting rows.
2. Setting the 起运港 input's displayed text alone did not satisfy required-field validation; blur/Tab committed the value to the form model.
3. Warehouse lookup selection must be verified after the lookup window closes for every detail row.
4. Document submission and workflow audit are separate asynchronous stages. Wait for the submission success message before opening audit, then wait for the audit workflow result without repeated clicks.

Cases are evidence, not a blanket authorisation for future mutations.
